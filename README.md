# NAFATH-V4 Cybersecurity Brief

This repository contains my research for the NAFATH-V4 Discovery Mission, focusing on cybersecurity.

I explored six areas: Software, AI, Mobile, Networking, Cybersecurity, and Data. For each area, I looked at a real security issue, explained how it works, and included a source for further reading.

The research also covers a common misconception about software dependencies and raises a question about how small cybersecurity teams can identify vulnerable libraries.

- [Research Brief](brief.md) – My research on the six topics, including examples and references.
